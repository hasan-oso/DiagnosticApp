## 📋 Overview

This document establishes branding guidelines for the DiagnosticApp project.
All use of the DiagnosticApp brand must comply with these guidelines.

---

## 🏷️ Brand Name

### Primary Name
- **DiagnosticApp** (one word, capital D and A)

### Full Name
- **DiagnosticApp — AI-Powered Device Health Analysis**

### Incorrect Usage
- ❌ Diagnostic App (two words)
- ❌ diagnosticapp (all lowercase)
- ❌ DIAGNOSTICAPP (all caps)
- ❌ Diagnostic-App (hyphenated)
- ❌ DiagApp (abbreviated)

## 🔤 Typography

### Recommended Fonts
- **Headlines**: Roboto Bold / Inter Bold
- **Body**: Roboto Regular / Inter Regular
- **Code/Data**: JetBrains Mono / Fira Code

### Font Sizes (Mobile)
| Element | Size | Weight |
|---------|------|--------|
| App Title | 24sp | Bold |
| Section Header | 20sp | SemiBold |
| Body Text | 16sp | Regular |
| Caption | 12sp | Regular |
| Data Values | 14sp | Medium |

---

## 📐 Logo Usage

### Minimum Clear Space
- Maintain a minimum clear space equal to the height of the "D" in
  DiagnosticApp around the logo on all sides.

### Minimum Size
- Digital: 32px height minimum
- Print: 10mm height minimum

### Don'ts
- ❌ Don't stretch or distort the logo
- ❌ Don't change the logo colors
- ❌ Don't add effects (shadows, outlines)
- ❌ Don't place on busy backgrounds without contrast
- ❌ Don't use the logo to imply endorsement
